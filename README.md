# Isolated EyeOnAds beta

Separate beta source and hosting only. No customer production database, accounts,
secrets or deployment privileges are permitted here. Beta Buddy can propose only
registered ordinary display repairs; access, privacy, money, schema and contract
changes require human review. Feature requests never enter the repair loop.

`main` holds operator-reviewed code and independent verification definitions.
`beta-release` is the only automatically deployable product branch. Verified
candidates are published there only after independent isolated checks pass.
The report service is separate from this application and is already deployed.

The repository is being provisioned; creation of this README is not evidence
that the application or autonomous repair loop is ready.
